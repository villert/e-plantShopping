# Paradise Nursery Shopping Application

Paradise Nursery is a React + Redux shopping cart application built to satisfy the Final Project assignment requirements for a plant shop web application.

## Features

- 3 product categories with 6 unique houseplants per category
- Category grouping with thumbnails, names, descriptions, and prices
- Add to Cart buttons per plant
- Cart icon badge updates dynamically as plants are added
- Cart page shows total item count, pricing, quantity controls, and remove support
- "Checkout" button shown with a "Coming Soon" message
- Continue shopping button returns to plant listing
- About page for the company

## Setup

1. Run `npm install`
2. Run `npm run dev`
3. Open the local Vite URL shown in the terminal
